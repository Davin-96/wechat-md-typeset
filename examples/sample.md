# 写了 300 篇推文后，我留下的 5 条排版原则

> 内容决定读者会不会来，排版决定他会不会读完。

刚做公众号那两年，我把大部分时间花在改标题上，直到一位读者留言说："文章挺好，就是看着太累。"那之后我才认真研究排版——**它不是装饰，是阅读体验的一部分**。

## 01 先让读者「扫」得动

手机屏幕窄，读者习惯先扫一遍再决定读不读。所以：

- 每段不超过 4 行，段间留白
- 小标题用编号，进度感更清楚
- 关键信息**加粗**，但一段里别超过两处

## 02 强调要克制

`加粗`、*斜体*、[链接](https://example.com) 各有各的用途，堆在一起就等于没有重点。我的做法是一屏之内只强调一个层次。

| 元素 | 用途 | 建议频率 |
| --- | --- | --- |
| 加粗 | 结论 | 每段 ≤ 2 处 |
| 引用 | 观点 / 金句 | 每篇 1–2 处 |
| 代码块 | 步骤 / 命令 | 按需 |

## 03 引用是节奏，不是填充

> 好的排版会让读者忘记排版的存在的。

## 04 代码和步骤要给全

```js
const theme = THEMES.builtinConfigs.find(t => t.id === 'moyu');
const result = Engine.render(markdown, theme);
preview.innerHTML = result.html;
```

## 05 最后留一句人话

工具能解决一致性，解决不了真诚。写完记得自己从头读一遍。
